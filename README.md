# mouse-bias
Source data and code used in the paper "Single neurons in the medial prefrontal cortex encode social group influence and conformity" forthcoming in Nature Neuroscience.

Folder **data** contains the source data. 

Folder **GigE_Record** contains a function to capture video and a single digital input for alignment with neurophysiological data and for parsing trials.

Folder **Identity Corrector** contains a function to manually correct animal tracks and animal identities that were generated by the toolbox MOTR https://motr.janelia.org/
