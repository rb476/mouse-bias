# mouse-bias
Custom code used in the paper "Single -neurons in the medial prefrontal cortex encode social group influence and conformity" forthcoming in Nature Neuroscience.

GigE_Record is a function to capture video and a single digital input for alignment with neurophysiological data and for parsing trials.

Identity Corrector is a function to manually correct animal tracks and animal identities that were generated by the toolbox MOTR https://motr.janelia.org/
